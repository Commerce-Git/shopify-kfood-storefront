# Local fonts

Unmodified variable TrueType fonts from the Google Fonts repository:

- Inter: https://github.com/google/fonts/tree/main/ofl/inter — see inter-OFL.txt.
- Outfit: https://github.com/google/fonts/tree/main/ofl/outfit — see outfit-OFL.txt.

Downloaded 2026-09-23. `app/layout.tsx` uses `next/font/local`, preserving the existing CSS variables and font families without build-time downloads.
