## Part 1: 지금 필요한 것 (MVP 랜딩 페이지)

### 원칙
1. **3스크롤 안에 결제 버튼**이 보여야 한다
2. **과자 사진이 맛있어 보여야** 한다 (카피보다 비주얼이 중요)
3. **실제 사실만** 쓴다 (가짜 숫자, 가짜 리뷰 절대 금지)
4. CTA는 명확하고 행동 지향적으로

### 페이지 구조 (위에서 아래)

```
┌───────────────────────────────────────┐
│ 1. Hero                               │
│    왼쪽: 헤드라인 + 가격 + CTA          │ ← 3초 안에 "이건 과자 박스다" 인지
│    오른쪽: 열린 박스 이미지              │
├───────────────────────────────────────┤
│ 2. What's Inside (구성품)              │ ← "뭐가 들어있지?" 호기심 해소
│    스낵 6종 카드 그리드                  │
├───────────────────────────────────────┤
│ 3. Trust Badges                       │ ← 실제 차별점 3개
│    서울 직배송 / FDA 통관 / 100% 정품    │
├───────────────────────────────────────┤
│ 4. FAQ                                │ ← 구매 전 걱정 해소
│    배송, 관세, 환불, 구독 여부           │
├───────────────────────────────────────┤
│ 5. Sticky Buy Bar                     │ ← 스크롤 시 항상 따라다니는 CTA
└───────────────────────────────────────┘
```

### 섹션별 가이드

#### Hero
- **헤드라인**: "Stop Watching K-Dramas. Start Tasting Them." ✅ 유지
- **서브카피**: 짧게. "10+ trending Korean snacks. Shipped from Seoul. 5-10 days."
- **가격**: $39.99 + ~~$54.99~~ 할인 표시
- **CTA**: "Yes! Send Me The Snack Box 🎁"
- **이미지**: 목업 박스 사진 (현재 적용됨)

#### What's Inside
- 실제 박스에 들어가는 과자 6종 사진 + 이름
- 현재 mock 데이터 → **상품 등록 후 실제 데이터로 교체**

#### Trust Badges
- ✈️ Direct from Seoul — 서울에서 직배송
- ✅ FDA Compliant — 미국 통관 완료
- 💯 100% Authentic — 정품만 취급
- (이 3가지는 **실제 사실**이므로 적절)

#### FAQ (구매 저항 해소)
- "배송 얼마나 걸려?" → 5-10 business days, EMS
- "관세 내야 해?" → $800 이하 면세 (de minimis)
- "마음에 안 들면?" → 환불 정책 안내
- "구독이야?" → 아니요, 1회 구매입니다

#### Sticky Buy Bar
- "Claim My Box 🎁" 버튼 ✅ (현재 적용됨)

### 제거/보류할 것

| 항목 | 현재 상태 | 액션 |
|---|---|---|
| EpiphanyStory (4단락 스토리) | 구현됨 | **제거 또는 1문장으로 축약** |
| ProductShowcase (별도 섹션) | 구현됨 | Hero에 통합하여 **중복 제거** |
| Reviews (가짜 리뷰 6개) | 구현됨 | **제거** (진짜 리뷰 생기면 복원) |
| SocialProofBar | 미구현 | **보류** (실제 수치 생기면 추가) |

## Part 2: 나중에 할 것 (첫 판매 이후)

### 10건 판매 달성 후
- [ ] 실제 고객 리뷰 수집 → Reviews 섹션 복원
- [ ] 고객 UGC (언박싱 사진) 요청 → 신뢰도 강화
- [ ] Google Analytics 설치 → 이탈 지점 파악

### 50건 판매 달성 후
- [ ] A/B 테스트 시작 (헤드라인, CTA 색상)
- [ ] 이메일 수집 시작 (뉴스레터 또는 할인 코드)
- [ ] 재구매율 분석 → 구독 모델 검토 여부 결정

### 100건+ 판매 달성 후
- [ ] Value Ladder 2단계 상품 기획 (K-Ramen Box 등)
- [ ] Order Bump / 추가 상품 제안 기능
- [ ] 본격적인 Russell Brunson 퍼널 적용 (OTO, Downsell)
