# 🎨 Blank Seoul — Visual Brand Guideline

> 이 문서는 Blank Seoul의 모든 비주얼 작업(웹사이트, SNS, 광고 등)의 기준점입니다.
> 이미지를 제작하거나 교체할 때 반드시 이 원칙에 따릅니다.

---

## 🧠 핵심 원칙

### "한국을 보여주지 말고, 한국 상품이 있는 라이프스타일을 보여줘라."

한국의 전통은 한국인에게는 자부심(국뽕)이지만, 외국인에게는 **수많은 디자인 스타일 중 하나**에 불과합니다. 한류 덕분에 한국 문화에 관심이 있지만, 결국 그들이 돈을 쓰는 이유는 **"이 상품이 내 일상을 더 아름답게 만들어주기 때문"**입니다.

---

## ❌ 하지 말아야 할 것 (Anti-Patterns)

| 유형 | 예시 | 왜 안 되는가 |
|---|---|---|
| 한국 풍경 중심 | 한옥 골목, 고궁, 서울 야경 | "여행 사이트"처럼 보임. 상품 구매 욕구와 무관 |
| 박물관 스타일 정물화 | 어두운 배경에 전통 공예품 나열 | "문화재 전시"처럼 느껴짐. "갖고 싶다"가 아닌 "보기 좋다"로 끝남 |
| 순수 전통 이미지 | 한복 차림의 인물, 전통 공방 내부 | 외국인에게 "나와는 먼 세계"라는 거리감 형성 |
| 무국적 미니멀리즘 | 하얀 배경에 상품만 덩그러니 | 한국적 특색이 없어짐. Muji와 구분 불가 |

---

## ✅ 해야 할 것 (Best Practices)

### 이미지의 목표: 외국인이 "나도 이렇게 쓰고 싶다"고 느끼게 만들기

| 원칙 | 구체적 실행 |
|---|---|
| **상품을 일상 속에 배치** | 맥북 옆의 보자기 파우치, 가방에 달린 노리개 키링, 선반 위의 부채 아트 |
| **현대적 공간이 배경** | 모던 카페, 밝은 아파트, 스칸디나비안 스타일 거실 |
| **"사용 중인" 순간 포착** | 가방에 넣는 손, 책상 위에 놓인 모습, 벽에 걸린 상태 |
| **자연광 + 따뜻한 톤** | 골든아워 느낌, K-Drama 색감, 부드러운 보케 |
| **한국 상품이 디자인 액센트** | 전체 씬의 주인공이 아닌, 공간을 돋보이게 하는 포인트 아이템 |

---

## 📸 이미지 제작 시 체크리스트

새 이미지를 만들거나 교체할 때 아래 질문에 모두 "예"여야 합니다:

- [ ] 외국인이 이 사진을 보고 **"나도 저 상품을 갖고 싶다"**고 느끼는가?
- [ ] 상품이 **현대적인 라이프스타일 속**에 자연스럽게 녹아 있는가?
- [ ] 배경이 한국 풍경이 아닌 **고객이 살 수 있는 공간(카페, 집, 사무실)**인가?
- [ ] 상품이 **실제로 사용되고 있는 맥락**이 보이는가?
- [ ] **따뜻한 자연광**이 느껴지는가?

## 🎯 타겟 고객의 심리

```
"한국 드라마에서 본 그 감성, 나도 일상에서 느끼고 싶다."
"이 파우치를 카페에서 꺼내면 친구들이 물어볼 거야."
"이 부채를 벽에 걸면 내 방이 확 달라질 거야."
"이 키링을 가방에 달면 유니크하면서도 세련될 거야."
```

**핵심 감정: Aspiration(동경) + Uniqueness(유니크함) + Belonging(K-Culture 소속감)**

## 📷 상품 사진 촬영 가이드

### 기본 원칙

> 외국인은 한국 전통 공예품을 처음 봅니다.
> **"이게 뭐지?"**가 아니라 **"이걸 이렇게 쓰는 거구나!"**를 사진으로 보여줘야 합니다.

### 이미지 타입별 역할

| 이미지 타입 | 역할 | 사용처 |
|---|---|---|
| **연출 사진 (Lifestyle)** | "이렇게 쓰는 거야" — 구매 욕구 자극 | PDP 메인, 인스타, 광고 |
| **단독 컷 (Clean)** | "실물은 이렇게 생겼어" — 신뢰 확보 | 목록 그리드, PDP 갤러리 |
| **디테일 컷 (Close-up)** | "마감이 이렇게 꼼꼼해" — 품질 증명 | PDP 갤러리 |
| **크기 비교 (Scale)** | "실제 크기는 이 정도야" — 기대치 관리 | PDP 갤러리 |
| **패키징 컷 (Packaging)** | "이렇게 포장돼서 와" — 선물 욕구 | PDP 갤러리, 인스타 |

---

### 상품 목록 (그리드) 썸네일

**스타일:** 밝은 자연광 + 린넨 천 or 밝은 나무 위에 상품 단독 촬영

| ❌ 피할 것 | ✅ 해야 할 것 |
|---|---|
| 순수 흰 배경 (아마존/쿠팡 느낌 → 저가 인식) | 따뜻한 자연광 배경 (프리미엄 느낌) |
| 셀러마다 다른 스타일 | 전체 그리드에 통일된 톤 |
| 어두운 배경, 그림자 과다 | 밝고 깨끗한 톤 |

---

### 상품 상세 (PDP) 갤러리 순서

```
사진 1: 🎬 연출 사진 — 라이프스타일 맥락 (메인 이미지)
사진 2: 📸 깔끔한 단독 컷 — 실물 확인
사진 3: 🔍 디테일 클로즈업 — 소재·마감 품질
사진 4: 📏 크기 비교 — 손 위에 올려놓은 모습
사진 5: 🎁 패키징 — 포장 상태 / 선물 연출
```

---

### 상품별 연출 사진 가이드

| 상품 카테고리 | 연출 컨셉 | 핵심 메시지 |
|---|---|---|
| **노리개 키링** | 가방 지퍼에 달린 클로즈업, 카페 배경 | "가방에 달면 유니크한 포인트" |
| **보자기 파우치** | 화장품·소지품을 넣고 꺼내는 손 | "예쁜 화장품 파우치로 쓰는 거구나" |
| **부채** | 벽에 걸린 모습, 모던 인테리어 배경 | "벽 아트로 걸면 인테리어 포인트" |
| **코스터** | 모던 테이블 위, 커피잔 아래 | "매일 쓰는 컵 받침이 이렇게 예쁠 수 있다" |
| **비녀/머리 액세서리** | 머리에 꽂은 뒷모습 (얼굴 안 보이게) | "헤어 스타일링의 유니크한 마무리" |
| **카드지갑** | 카드를 넣고 빼는 손, 카페 테이블 | "실용적이면서 예쁜 지갑" |
| **반다나/스크런치** | 손목에 감거나 머리에 묶은 모습 | "일상 패션 액세서리" |
| **도어벨** | 현관문에 달린 모습 | "집에 들어올 때마다 기분 좋은 소리" |

---

### 촬영 세팅 (아이폰으로도 충분)

- **조명:** 창가 자연광 (오전 10시~오후 2시 최적)
- **배경:** 린넨 천, 밝은 나무 테이블, 대리석 (2~3가지 교체 사용)
- **소품:** 커피잔, 드라이플라워, 캔들 등 최소한만 (상품이 주인공)
- **각도:** 45도 앵글 (기본), 정면 (디테일), 탑뷰 (플랫레이)
- **편집:** 밝기↑, 따뜻한 톤, 채도 약간↑ — 과하지 않게

## 📝 향후 적용 범위

이 가이드라인은 다음 작업에도 동일하게 적용됩니다:

1. **SNS 콘텐츠** (인스타그램/틱톡 피드 이미지)
2. **상품 사진** (개별 PDP 이미지)
3. **광고 크리에이티브** (Facebook/Instagram Ads)
4. **이메일 마케팅** (뉴스레터 헤더 이미지)
5. **패키징 디자인** (언박싱 경험)

> **기억할 것:** 우리는 "한국"을 파는 게 아니라, **"한국 감성이 녹아든 더 아름다운 일상"**을 파는 것이다.
