## 현재 상태

storefront에서 실행 가능한 파이프라인을 구성했고, 실제 모델을 연결한 작은 작업이 최종 APPROVED까지 완료되었습니다. Supabase SQL 실행·마이그레이션 적용·Git push·배포는 계속 사용자 수동 작업입니다.

## 완료한 작업

- 작업 루트와 제어 경로 검증, Codex 읽기 전용 계획/검토, macOS 테스트 샌드박스.
- 테스트 전체 통과 + 같은 실행의 새 APPROVED를 성공 조건으로 적용.
- 테스트 실패 시 유료 Codex 검토를 건너뛰고 Gemini 수정으로 이동.
- Antigravity SUCCESS JSON과 새 COMPLETED 보고서 확인. 이전 승인/보고서 재사용 방지.
- 실행 잠금, 시간 제한, 자식 프로세스 종료 및 실패 상태 기록.
- Antigravity 전용 프로젝트 `agent-bridge-storefront`: storefront 폴더만 등록하고 해당 경로 신뢰·파일 접근 설정. 기존 사용자 설정은 백업·보존.
- 등록 MCP가 없음을 확인했고, 서버가 구성되면 실행 전 중단하는 사전 검사 추가. 전역 MCP 설정 자동 변경 없음.
- 기존 lint 오류 40개 수정: 예외 타입 좁히기, 응답/테스트 데이터 타입, 외부 저장소 구독, 파생 상태와 Hook 의존성 정리. 규칙 비활성화 없음.
- Inter·Outfit 폰트를 라이선스와 함께 로컬 제공.
- 오프라인 빌드 스크립트, 테스트용 환경값 및 별도 `.next-offline` 출력 경로. 검사가 tsconfig를 변형하지 않도록 타입 경로 명시.
- 브라우저 저장소 이벤트·미리보기 데이터·예외 처리 회귀 테스트 추가.
- 전역 `~/.local/bin/agent-bridge`에 프로젝트 실행기와 동일한 최종본 설치.

## 사용 조건과 검증 범위

- 일반 `npm run build`는 Turbopack을 사용합니다. Turbopack의 PostCSS가 로컬 포트를 필요로 하므로 네트워크 차단 검증은 webpack을 사용합니다. 이를 일반 Turbopack 배포 빌드의 성공으로 간주하지 않습니다.
- 테스트용 URL·키로 정적 페이지를 생성하며 데이터 요청 실패 시 빈 결과를 처리하는 경로도 있습니다. 외부 연동·실제 상품 데이터·결제·브라우저 상호작용은 이번 오프라인 검사로 검증되지 않습니다. `.next-offline`은 배포하지 않습니다.
- lint 경고 24개는 남아 있습니다. 주로 이미지 요소와 미사용 선언에 대한 경고이며 통과 기준을 낮추거나 숨기지 않았습니다.
- 작은 실제 모델 과제 성공은 모든 향후 과제의 무인 완료를 보장하지 않습니다. 권한 대기, 시간 초과, 실패 테스트는 계속 중단 또는 수정 반복으로 처리합니다.
- 현재 테스트 격리는 macOS 전용입니다. 다른 OS에서는 일반 실행으로 전환하지 않고 중단합니다.
- 파일 스냅샷은 변경 감지 기능으로, 무시된 파일 전체나 MCP 외부 부작용까지 포괄하는 격리 장치는 아닙니다. 변경을 자동 되돌리지 않습니다.
- 자동 구현은 변경을 검토·커밋한 깨끗한 작업 트리에서 실행합니다. `--allow-dirty` 사용 시 기존 작업 보존을 완전히 보장하지 않습니다.

권한 설정과 복구 안내는 [SAFETY.md](SAFETY.md), 실행 방법은 [PIPELINE.md](PIPELINE.md)를 참고하세요.

## 모델 설정 변경 — 2026-09-23

계획·검토 모델과 새 프로젝트 초기화 기본값을 `gpt-6-sol`로 변경했습니다. 두 단계의 추론 강도는 `high`이며 Gemini는 `gemini-3.8-flash` / `high`를 유지합니다. 현재 계정의 Codex CLI에서 `gpt-6-sol` / `high`로 짧은 실제 호출에 성공했습니다(OK, exit 0). `LIVE_SMOKE.md`는 이전 `gpt-5.6-sol`로 수행한 전체 통합 검증 기록이므로 그대로 보존합니다. 새 모델의 전체 파이프라인 통합 검증을 수행한 것으로 간주하지 않습니다.
